# 季节与日历调整设计说明

本文件记录在既有月度资料组件上新增的可复算季节/日历调整能力。数据语义与读取约定见
[资料契约](data-contract.md)；本文档只描述分析方法学、防前视约束、诊断口径与冻结复算。
所有实现仅使用 Python 标准库（运行环境 Python 3.11+，无 numpy/scipy 依赖）。

## 1. 设计目标与契约遵循

研究者需要把一条工业月度序列分解为**长期趋势水平、季节项、春节移动窗口、交易日效应、
已知干预、异常观测与残差**，而不是把春节低点当作噪声抹平。对应约束：

- **工作日设计**：严格按契约，交易日对比以星期日为基准，`weekday_counts` 前六项分别
  减最后一项，生成 6 个交易日回归列（`td_mon … td_sat`）。
- **春节移动窗口**：直接使用 calendar 集合中事前固定的 `holiday_overlap` 标量权重
  （单一回归列 `holiday_spring`），权重不从产量序列拟合，避免循环论证。
- **已知干预**：来自 `metadata.interventions`，含 `pulse` 与 `level_shift` 两类，
  带 `active_as_of` 表示该信息首次可知的时点；绝不从数据反推。
- **公布版本**：`as_of` 筛发布时间，同 series/month 取最高 revision，冲突拒绝；
  每次公布是独立 id，旧公布事件保留。
- **联合估计**：日历回归（交易日 + 春节）、季节项、干预/异常虚拟与 AR(p) 误差在
  **同一个 FGLS 条件最小二乘**中共同估计，不存在“先全样本平滑、再对平滑结果挑异常”
  的两步法。

## 2. 模块结构

| 模块 | 职责 |
| --- | --- |

| `app/stats.py` | 不完全伽马/贝塔函数、χ²/F 上尾概率、ACF、Ljung–Box、按月份分组的季节 ANOVA |

| `app/arima.py` | 回归 + AR(p) 误差的 FGLS 联合估计、条件似然、BIC/AICc、t 值 |
| `app/selection.py` | 季节规格 × AR 阶数候选的 BIC 选择，秩亏候选剔除 |

| `app/freeze.py` | 冻结负载的重放与逐项核对 |
| `app/service.py` | `inspect`（兼容）/ `adjust` / `realtime` / `replay_frozen` 入口与 CLI |

## 3. 变换与非正值退路

每个 vintage 内基于该 cutoff 可见观测独立判定，不使用未来信息：

- 全部为正 → **对数变换（乘法分解）**；
- 出现零或负值 → **恒等变换（加法分解）**，并在 `transform.reason` 记录触发原因与
  非正观测数量；
- 可通过 `force_transform` 强制口径；强制对数但存在非正值时直接报错。

对数口径下三条主序列（未调整、日历调整、季调）用精确指数公式定义；逐项“原始尺度成分”
是边际近似（乘法下各效应不严格可加），同时输出 `components_transformed`（变换尺度精确
可加成分）供严格复算，并在 `component_note` 注明。

## 4. 联合估计模型

对变换后的序列 z(t)：

```
z(t) = X(t)·β + u(t),   u(t) = φ1·u(t-1) + … + φp·u(t-p) + ε(t),  ε ~ iid N(0, σ²)
```

设计矩阵 X 的列分组：`intercept`（趋势水平）、`trading`（6 列）、`holiday`（春节窗口）、
`seasonal`、`intervention`、`outlier`。

- 估计采用 **Cochrane–Orcutt 型可行广义最小二乘**：Yule–Walker 估 AR 系数 → AR 过滤
  设计行与响应 → OLS 估 β → 迭代至收敛。AR 系数非平稳时自动降阶。
- 似然基于**条件最小二乘有效样本**（t=p+1…n，n−p 个新息），保证不同 AR 阶数间 BIC
  可比（这是关键：若用含缩放误差的全样本似然，AR 项会被系统性误罚）。
- 近奇异设计走列主元 QR 回退，保证脉冲列早期仅单个非零元时仍可估计。

## 5. 模型选择（只用 cutoff 可见数据）

候选集 = 季节规格 `{fixed, trig3, trig6}` × AR 阶数 `{0,1,2}`，共 9 个。

- `fixed`：11 个月份虚拟（1 月基准）；`trig3`/`trig6`：3 或 6 个谐波的正余弦对。
- 按 **BIC** 选择（AICc 同时返回备查）；秩亏或样本不足的候选剔除并记录原因。
- 选择在每个 vintage 独立进行，输入仅为该 cutoff 的可见观测，无全样本信息。
- 固定口径对照（`fixed_spec`）跳过选择，用于实时分析中隔离“重新选模”效应。

## 6. 无前瞻异常检测（核心防作弊约束）

需求明确禁止“先用全样本平滑结果挑异常，再拿同一结果宣称历史预测好”。实现采用
**严格因果的滚动外部学生化残差**（`app/outlier.py`）：

1. 评估第 i 个月时，设计矩阵只包含截至该月的行；`frame.window(end_month)` 重建子窗口，
   未来才发生的干预列在该窗口内为零列并被剔除——早期观测的设计不携带任何未来信息。
2. 随窗口增长逐月做列主元 QR 最小二乘；对当月计算 **externally studentized residual**
   （该月不参与 SSE 估计，leave-one-out 口径），|t| > 3.5 才标记为脉冲虚拟。
3. 标记后该脉冲成为设计列，后续月份在含该列的模型下评估；脉冲数设上限（默认 5% 样本）。
4. **设计外推点（杠杆 h>1）不标记为异常**，只在轨迹中留痕（`design_extrapolation`），
   因为外推区域的学生化值统计上不可靠——这保护了春节等天然落在设计薄区的低点不被误杀。
5. 实时分析中对最终 vintage 检测一次，旧 vintage 只取用其 cutoff 之前已确认的脉冲，
   天然保持因果；测试 `test_flag_decision_does_not_use_future_rows` 验证缩短 cutoff
   不改变任何早期标记决策。

已知干预与检测异常的区别：干预是事前清单（`metadata.interventions`），异常是数据驱动、
但仅用过去数据识别。两者作为不同分组的虚拟列进入同一联合估计。

## 7. 三条输出序列与成分

每次调整同时保存（每行一组，对齐到实际月份与记录 id/revision）：

- `unadjusted`：原始观测；
- `calendar_adjusted`：移除交易日 + 春节窗口效应（保留季节项）；
- `seasonally_adjusted`：再移除季节项（保留干预/异常成分，不把真实冲击抹掉）。

另输出变换尺度精确成分、残差 `residual`、AR 白化新息 `innovation`、趋势水平与各分组
原始尺度贡献。干预与异常**不**从季调序列中删除，研究者可单独审视。

## 8. 诊断（三类，均不伪造 p 值）

- **残留季节性**：按 12 月份分组的单因素 ANOVA F 检验（避开虚拟矩阵近奇异）；
  自由度不足或组内方差近零时如实标记 `evaluated=false` 与原因。
- **残差相关**：对 AR 白化后的新息做 Ljung–Box（lag 12 与 24），自由度扣减 AR 项数。
- **模型不可识别**：列主元秩、零列、列标准化后的条件数（近无限时输出 `"infinite"`
  而非非有限浮点）、被剔除的未发生干预列；`identifiable` 综合满秩与条件数阈值。

## 9. 端点处理与延拓

模型法（回归 + AR）不使用 X-11 式对称滤波器，因此**没有对称滤波器固有的末端偏差**。
仍按需求提供可选端点延拓（`forecast_horizon`）：用估计的系统成分 + AR 递归向前预测，
预测标准误随视野按 AR 脉冲响应累积扩大。所有延拓点 `forecast=true` 并单列于
`endpoint_extension`，与观测月的三条序列物理隔离；cutoff 之后无日历资料时返回
`available=false` 与原因。默认关闭。

## 10. 实时修订分析与三效应分解（末端修订）

`app/realtime.py` 按历史发布时点（vintage）逐步扩展样本，提供两条轨道：

- **evolving**：每个 vintage 独立做无前瞻异常检测与 BIC 选模，反映真实生产流程；
- **fixed**：在首个合格 vintage 冻结模型口径（季节规格 + AR 阶数）与变换，之后不变。

对相邻 vintage（c0→c1）的每个共同月 m，通过三次受控重估把总修订严格分解为三项，
且**精确加总**（测试断言残差为 0）：

```
total        = SA(c1, 全样本, 新模型) − SA(c0, 旧样本, 旧模型)
revision     = SA(c1 数据, 仅旧窗口, 旧模型) − SA(c0)          # 历史值被修订
new_month    = SA(c1 全样本, 旧模型) − SA(c1, 仅旧窗口, 旧模型) # 新增月参与估计
reselection  = SA(c1, 新模型) − SA(c1, 旧模型)                 # 重新选模
```

固定轨道的 `reselection_effect` 恒为 0，因此数据修订与模型修订不会被混成一个
“修订小”。汇总同时给出各效应的平均绝对量与 RMSE。早期样本不足的 vintage 进入
`skipped_vintages` 并记录原因。

## 11. 序列间复用与隔离

同一 cutoff、同一观测月份集合下，多个序列**复用同一个 `DesignFrame`**（日历设计列相同）；
但每个序列独立估计 β、φ、σ² 与异常脉冲，参数与调整结果不串用。序列特异的异常列只进入
对应序列的设计（见 `test_shared_design_but_separate_parameters`）。

## 12. 冻结与可追溯

每次调整的 `freeze` 负载自包含：输入摘要 `input_digest`、实际月份/观测/记录 id/revision、
变换选择理由、完整设计矩阵（月份+列名+分组+数值）、选模候选表、异常检测轨迹、估计参数
（β/φ/σ²/似然/BIC）与诊断摘要。`app/freeze.replay` 脱离原始快照即可重放并逐元素核对，
容差内不一致会抛 `ReplayMismatch`。冻结后仍能追到**实际月份、设计矩阵与模型**三要素。

## 13. 合成夹具与可证伪性

`fixtures/generate_sample.py`（固定随机种子）生成 `sample_long.json`：6 年 × 3 序列，
DGP 含已知乘法季节因子、交易日效应、漂移春节窗口、AR(1)/(2) 噪声、事前干预（脉冲/水平
迁移）、植入的单点异常、3 个历史修订月，以及一个含零值的序列（检验对数退路）。DGP 参数
写入 `metadata.dgp`，使“季调是否还原已知成分”“异常是否被无前瞻检出”“修订是否被正确
归因”都可证伪。该数据为合成数据，不对应真实企业或个人。
